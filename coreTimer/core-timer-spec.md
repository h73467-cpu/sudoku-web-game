## 1. 設定項目（開始運動前可調整）

| 項目 | 預設值 | 可調整範圍 | 說明 |
|---|---|---|---|
| 每下持續時間 | 10 秒 | 不設上限，最小 1 秒 | 「核心動作」階段長度 |
| 每次休息時間 | 20 秒 | 不設上限，最小 0 秒（0 = 不休息） | 兩下之間的休息長度 |
| 總共要做幾下 | 30 下 | 不設上限，最小 1 下 | 總循環次數 |
| 顯示方式（每項獨立切換） | 倒數 | 倒數／正數 | 「每下時間」「休息時間」「總次數進度」三者各自可切換 |
| 提示音方式 | 語音報數 | 語音報數／嗶聲／語音＋嗶聲 | 每秒報數用哪種音效 |
| 背景音樂 | 無 | 無／5 首之一 | 見第 4 節 |
| 音樂音量 | 中（0.22） | 小(0.11)／中(0.22)／大(0.34)／最大(0.46) | 執行中即時可調 |

## 2. 運動流程

```
[5 秒預備]（僅第一次）→ [核心動作] → [休息]（若休息秒數 > 0）→ [核心動作] → ... → 完成
```

- **只有整個運動一開始**才有固定 **5 秒預備倒數**
- **每次休息結束後**（或休息秒數設為 0、緊接著下一下時），**不再重複 5 秒預備倒數**，會直接播放「開始長音」後進入核心動作
- 核心動作開始的瞬間（不論是第一次預備結束後，還是休息結束後）：播放 **2 秒長音**（上揚音，模擬起跑訊號），畫面短暫顯示「GO」
- 核心動作結束、進入休息前：播放 **2 秒放鬆鈴聲**（多泛音疊加，模擬鐘聲），畫面短暫顯示 🔔
- 這兩個轉場音效**固定會播放**，不受「提示音方式」設定影響
- 若休息秒數設為 0，則跳過休息階段，直接播放開始長音進入下一次核心動作

## 3. 每秒報數邏輯

- 每秒觸發一次，依「倒數／正數」設定決定顯示與唸出的數字
  - 例：核心動作 10 秒、倒數模式 → 唸 10, 9, 8 ... 1
  - 例：核心動作 10 秒、正數模式 → 唸 1, 2, 3 ... 10
- 語音使用瀏覽器 Web Speech API，語言固定 `zh-TW`，只唸阿拉伯數字（會自動唸成中文發音）
- 嗶聲：核心動作用高音方波、休息用低音正弦波，方便閉眼用耳朵分辨目前在哪個階段
- 進度顯示「X / 總下數」：依「進度顯示方式」設定顯示剩餘或已完成的下數

## 4. 背景音樂（程式即時合成，非外部音樂檔）

用 Web Audio API 即時合成的 16-step 節奏音樂，不是真的音樂檔案，所以沒有版權問題、也不用額外下載檔案。

| 曲目 | BPM | 音階 | 鼓點型態 | 大鼓音色 |
|---|---|---|---|---|
| 動感節拍 | 140 | 小調五聲音階 | 四拍落地鼓 (four-on-floor) | 一般電子鼓 |
| 電音衝刺 | 150 | 多利安調式 | 切分節奏 | **加強大鼓**（見下） |
| 強力驅動 | 132 | 小調五聲音階 | 八分音符連續 | **加強大鼓**（見下） |
| 節奏心跳 | 126 | 大調五聲音階 | 四拍落地鼓 | 一般電子鼓 |
| 極速能量 | 144 | 多利安調式 | 切分節奏 | **加強大鼓**（見下） |

**「加強大鼓」音色設計**（電音衝刺／強力驅動／極速能量 三首使用）：
由三層聲音疊加而成，目的是比純電子嗶聲更有「被打擊」的臨場感：
1. 低頻 sub boom（正弦波，155Hz 快速下滑到 48Hz）— 鼓身低沉的「咚」
2. 中頻鼓體音（三角波，125Hz 下滑到 62Hz）— 讓聲音有形狀
3. 鼓槌敲擊瞬間噪音（濾波白噪音，短促 bandpass ~2200Hz）— 打擊的顆粒感
4. 三層一起經過 WaveShaper 類比飽和處理，讓音色偏溫暖

一般版大鼓（動感節拍／節奏心跳）：單純正弦波 150Hz 快速下滑到 45Hz。

其他樂器音色：
- 鈸/hi-hat：短促高通濾波白噪音
- 貝斯：在鼓點的同一拍上，用鋸齒波彈根音（低八度）
- 主旋律：每兩拍取音階中的一個音，用方波演奏

音樂音量預設 0.22（背景音樂 gain 值），刻意調低避免蓋過語音報數與嗶聲。暫停時音樂會停止，繼續時從節奏起點重新播放（不是接續暫停前的位置）。

## 5. 介面設計

- 響應式設計，電腦／平板／手機皆適用
- 主要色彩：深色背景（#14161A），三個階段各自對應顏色
  - 準備：琥珀色 `--prep: #F2C230`
  - 核心動作：珊瑚橘 `--work: #FF5A36`
  - 休息：青綠色 `--rest: #35C9C9`
- 字體：數字用 Space Grotesk（tabular-nums 對齊），內文用 Inter
- 大數字置中顯示，外圈顏色會依階段變化並有 pulse 動畫
- 可暫停/繼續、可中途結束（結束會直接回到設定頁）
- 頁尾固定文字：
  > This game's mechanics and concept were solely created by Pony Ferng, engineered in collaboration with Claude

## 6. 技術限制與已知取捨

- 使用 Wake Lock API 嘗試保持螢幕開啟，但手機瀏覽器切到背景/鎖屏時，JS 計時器與語音仍可能被系統暫停 —— 這是網頁 App（非原生 App）的天生限制，設定頁已有提示文字告知使用者
- 語音需要瀏覽器支援 Web Speech API；若不支援會自動略過語音、只保留嗶聲（若使用者選的是「語音」模式且瀏覽器完全不支援，則該次不會有聲音，可考慮之後加入偵測後自動退回嗶聲的邏輯）
- 音效解鎖：手機瀏覽器要求「使用者手勢後才能播放音效」，目前用第一次點擊畫面時解鎖 AudioContext，正常操作流程（先按設定、再按開始）不會有問題

## 7. 待確認/可能之後會問的方向

若之後想調整，以下是比較可能會被要求微調的地方，方便直接對照這份文件的章節去改程式：
- 想換大鼓音色的力度/悶重程度 → 對照「第 4 節」的加強大鼓三層疊加參數
- 想加共用大鼓到全部 5 首 → 修改 `TRACK_META` 裡每首的 `kickStyle` 欄位
- 想改變某個階段的顏色 → 對照「第 5 節」CSS 變數 `--prep` / `--work` / `--rest`
- 想調整轉場音效（開始長音／休息鈴聲）長度或音色 → 對照「第 2 節」，程式碼中對應 `playStartTone()` / `playRestBell()` 函式
