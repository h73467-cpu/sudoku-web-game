# 數獨 Sudoku

純 HTML / CSS / JavaScript 的數獨遊戲，沒有任何建置工具或第三方套件依賴。

## 如何開始遊玩

直接用瀏覽器（Chrome / Edge / Firefox）打開 `index.html` 即可，例如在檔案總管雙擊該檔案。

> 為了確保「雙擊即可玩」在所有瀏覽器都可靠，JavaScript 採用一般 `<script>` 標籤載入（而非 ES module）。ES module 在部分瀏覽器透過 `file://` 開啟時會受 CORS 限制而失敗，一般 script 標籤沒有這個問題。如果你偏好用本機伺服器開啟（例如 `python -m http.server`），也完全相容。

## 操作方式

- **選取格子**：滑鼠點擊棋盤格子，或用方向鍵移動選取。
- **填入數字**：選取空格後點擊下方數字鍵盤，或直接按鍵盤 1–9。
- **清除數字**：點擊數字鍵盤的「清除」，或按 Backspace / Delete。
- **筆記模式**：點擊「筆記模式」按鈕開啟後，點數字會切換候選數字（顯示為格子內的小數字），而不是直接作答；再點一次數字可取消該候選數字。快捷鍵：`N`。
- **提示**：點擊「提示」按鈕，會自動選一個尚未正確填寫的格子填入正確答案。每局預設 3 次，用完會停用按鈕。
- **新遊戲 / 切換難度**：點擊「新遊戲」或切換難度下拉選單會開始新的一局；若目前已有進度，會先跳出確認視窗避免誤刪進度。

## 功能特色

- **出題演算法**：以隨機化 backtracking 產生完整解答，再依難度挖空格子，並在挖空過程中持續檢查是否仍為「唯一解」。
- **難度分級**（保留提示數，數字愈少愈難）：
  | 難度 | 保留提示數 |
  |---|---|
  | 簡單 | 40–46 |
  | 中等 | 32–39 |
  | 困難 | 28–31 |
  | 專家 | 22–27 |
- **即時錯誤標示**：同一列/欄/九宮格出現重複數字時，相關格子會立即標紅；另外，數字本身沒有重複但與正確解不符時，格子會顯示較淡的「錯誤」底色以區別。
- **筆記/候選數字**：每格可記錄多個候選數字，方便手動推理。
- **計時與最佳紀錄**：計時器即時顯示，破紀錄時會寫入瀏覽器 `localStorage`，並在完成畫面標示「新紀錄」；最佳紀錄依難度分別保存，重新整理頁面後仍會保留。
- **進度自動保存**：遊戲過程中會持續存到 `localStorage`，重新整理頁面會自動恢復原本的棋盤與計時進度，不用重新開始。

## 已知取捨

- 「專家」難度在極少數情況下，為了避免出題時間過長，挖空邏輯可能會接受非嚴格唯一解的題目（機率極低）。這是刻意的效能取捨，而非程式錯誤。
- 若瀏覽器處於無痕模式導致 `localStorage` 無法使用，遊戲仍可正常進行，只是最佳紀錄與進度保存功能會靜默失效（不會跳錯誤訊息）。

## 檔案結構

```
index.html      版面骨架
style.css       樣式與響應式設計
js/sudoku.js    出題/解題/衝突檢查等純邏輯（不碰 DOM）
js/storage.js   localStorage 存取（最佳紀錄、進度保存）
js/game.js      遊戲狀態、計時器、提示、勝負判斷
js/ui.js        畫面渲染與事件綁定（唯一操作 DOM 的檔案）
```
