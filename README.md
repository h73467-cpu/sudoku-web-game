# 益智遊戲集

純 HTML / CSS / JavaScript 的益智遊戲集合，沒有任何建置工具或第三方套件依賴。目前收錄「數獨」「記憶翻牌」「1A2B 猜數字」「打磚塊」，首頁會陸續加入更多遊戲。

## 如何開始遊玩

直接用瀏覽器（Chrome / Edge / Firefox）打開根目錄的 `index.html` 即可，例如在檔案總管雙擊該檔案，選擇想玩的遊戲。

> 為了確保「雙擊即可玩」在所有瀏覽器都可靠，JavaScript 採用一般 `<script>` 標籤載入（而非 ES module）。ES module 在部分瀏覽器透過 `file://` 開啟時會受 CORS 限制而失敗，一般 script 標籤沒有這個問題。如果你偏好用本機伺服器開啟（例如 `python -m http.server`），也完全相容。

## 檔案結構

```
index.html          遊戲集首頁（選擇遊戲）
shared/style.css     共用樣式（主題色、按鈕、彈窗等元件）
shared/js/storage.js 共用 localStorage 存取核心 + 各遊戲的 storage 模組
shared/js/games.js   遊戲清單設定（新增遊戲只要在這裡加一筆）
shared/js/hub.js     首頁渲染與主題切換

sudoku/index.html    數獨
sudoku/style.css
sudoku/js/           出題/解題、遊戲狀態、畫面渲染

memory/index.html    記憶翻牌
memory/style.css
memory/js/           遊戲狀態、畫面渲染

guess/index.html     1A2B 猜數字
guess/style.css
guess/js/             遊戲狀態、畫面渲染

breakout/index.html  打磚塊
breakout/style.css
breakout/js/          即時物理迴圈、canvas 畫面渲染
```

存檔皆使用瀏覽器 `localStorage`（key: `sudoku.data`，內部依遊戲命名空間分開儲存），無痕模式下功能會靜默失效但不影響正常遊玩。

## 數獨

### 操作方式

- **選取格子**：滑鼠點擊棋盤格子，或用方向鍵移動選取。
- **填入數字**：選取空格後點擊下方數字鍵盤，或直接按鍵盤 1–9。
- **清除數字**：點擊數字鍵盤的「清除」，或按 Backspace / Delete。
- **筆記模式**：點擊「筆記模式」按鈕開啟後，點數字會切換候選數字（顯示為格子內的小數字），而不是直接作答；再點一次數字可取消該候選數字。快捷鍵：`N`。
- **提示**：點擊「提示」按鈕，會自動選一個尚未正確填寫的格子填入正確答案。每局 5 次，用完會停用按鈕。
- **新遊戲 / 切換難度**：點擊「新遊戲」或切換難度下拉選單會開始新的一局；若目前已有進度，會先跳出確認視窗避免誤刪進度。

### 功能特色

- **出題演算法**：以隨機化 backtracking 產生完整解答，再依難度挖空格子，並在挖空過程中持續檢查是否仍為「唯一解」。
- **難度分級**（保留提示數，數字愈少愈難）：
  | 難度 | 保留提示數 |
  |---|---|
  | 簡單 | 36–44 |
  | 中等 | 30–34 |
  | 困難 | 26–29 |
  | 專家 | 22–25 |
  - 另有「超簡單」難度，可自行輸入百分比（比「簡單」再少 X%），適合新手練習。
- **即時錯誤標示**：同一列/欄/九宮格出現重複數字時，相關格子會立即標紅；另外，數字本身沒有重複但與正確解不符時，格子會顯示較淡的「錯誤」底色以區別。
- **筆記/候選數字**：每格可記錄多個候選數字，方便手動推理。
- **計時與最佳紀錄**：計時器即時顯示，破紀錄時會寫入 `localStorage`，並在完成畫面標示「新紀錄」；最佳紀錄依難度分別保存，重新整理頁面後仍會保留。
- **進度自動保存**：遊戲過程中會持續存到 `localStorage`，重新整理頁面會自動恢復原本的棋盤與計時進度，不用重新開始。
- **每日挑戰**：每天固定題目（依日期產生），完成會累計連續天數。

### 已知取捨

- 「專家」難度在極少數情況下，為了避免出題時間過長，挖空邏輯可能會接受非嚴格唯一解的題目（機率極低）。這是刻意的效能取捨，而非程式錯誤。

## 記憶翻牌

- 翻兩張卡牌，圖案相同即配對成功，全部配對完成即過關。
- 難度分「超簡單（可調百分比）／簡單／中等／困難／專家」，對數從 3 對到 18 對不等。
- 每局有 3 次提示機會，會隨機翻開一組尚未配對的卡牌供你參考。
- 同樣支援進度自動保存、依難度分別統計最佳時間/翻牌次數/完成次數。

## 1A2B 猜數字

- 電腦隨機選一組不重複數字，玩家逐次猜測，回饋「A」（數字對、位置對）與「B」（數字對、位置錯）。
- 難度分「超簡單（可調百分比）／簡單（3 位）／中等（4 位）／困難（5 位）／專家（6 位）」，數字池固定 0–9（超簡單會縮小數字池）。
- 內建「筆記」表格：每欄對應同一個猜測位置（跟數獨的候選數字概念一樣），每欄可勾選一個以上的候選數字，純輔助記憶，不影響判定，也不會因為填答案/清除格子被自動清掉。
- 點一格選取、再從數字鍵盤點選數字即可填入該格，點別的格子可以直接改選，不用整組重打。
- 每局有 3 次提示機會，會直接告訴你某一位的正確數字。
- 同樣支援進度自動保存、依難度分別統計最佳時間/最少猜測次數/完成次數。

## 打磚塊

- 滑鼠移動、手指拖曳、或左右方向鍵控制板子；球黏在板子上，點擊畫面或按空白鍵發射。
- 起始難度「超簡單（可調百分比）／簡單／中等／困難／專家」只決定第 1 關的排數/球速/生命/板寬，難度越高第 1 關越硬。
- **無限關卡**：打完當前關卡就自動進下一關，關卡沒有上限；每關程序化生成，磚牆版型從滿版/金字塔/棋盤留空/**密室**（磚塊圍出房間、留一個缺口，球要鑽進去才打得到裡面）四種隨機選，耐打磚（要打好幾下）機率隨關卡數提高。
- **道具**：打破磚塊有機率掉落膠囊，板子接到才生效，約 65% 是好道具（分裂球、板子變長、機關槍自動掃射、多一命），35% 是壞道具（板子變短、球變快），皆為限時效果，到期自動復原。
- **音效**：Web Audio 即時合成、無音檔，撞牆/撞板/打磚/道具/過關/遊戲結束各有不同聲音，且會依連段/隨機做音高變化，避免死板；可一鍵開關。
- 屬於即時動作遊戲，用「暫停」（⏸ 或 Esc）取代其他遊戲的提示/回上一步功能；單局進行中不支援跨頁面重整續玩。
- 依起始難度分別統計最佳分數、抵達過的最高關卡、遊玩次數；遊玩紀錄記錄每次結束時的分數/關卡/用時。
