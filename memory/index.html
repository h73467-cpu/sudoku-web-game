📖 玩法說明

  • 盤面上有數對背面朝上的卡牌，每次點擊翻開兩張。
  • 兩張圖案相同即配對成功，會保留正面朝上；不同則短暫顯示後自動蓋回。
  • 把所有卡牌配對完成即過關，翻牌次數與花費時間越少越好。
  • 「超簡單」難度可自行輸入百分比，數字越大代表比「簡單」難度再少幾對，適合練習用。
  • 每局有 3 次「提示」機會，會隨機翻開一組尚未配對的卡牌讓你看一眼。
